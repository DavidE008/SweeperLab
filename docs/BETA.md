# Closed beta

Build the preview using the preview profile in eas.json. Record the commit, build link, phone, OS and tester result for each run.

1. Install on a second phone. Start Beginner, flag with both controls, request a hint and finish a match.
2. Pan an Expert board near its edge. Check for accidental reveals. Repeat with large text and a screen reader.
3. Background a match for one minute. Reopen offline after terminating the app. Compare board, flags and counters. Finish it and reopen twice; history should gain exactly one entry.
4. Ask five beginners to complete both lesson boards. Record who independently explains the second deduction. Target four of five.
5. Invite 8–12 testers after device checks pass. Ask which move they learned and whether they played again. Resolve lost games, crashes and misleading hints before submission.
6. Capture screenshots on the release build. Confirm the support contact, privacy disclosures, store identifiers and signing credentials with the publisher. Install the store-channel candidate before submitting.
