# SweeperLab Brand Notes

Use the uploaded logo palette as the source of truth:

| Token | Hex | Suggested use |
| --- | --- | --- |
| `brand.paper` | `#E6F9FF` | App background, panels, open cells |
| `brand.surface` | `#E7F4FD` | Secondary sections, modals, setup cards |
| `brand.line` | `#C0D2E1` | Borders, dividers, inactive UI |
| `brand.tile` | `#B9DCF8` | Highlight support, soft active states |
| `brand.primary` | `#297ECB` | Primary buttons, closed tiles, focused UI |

Contrast helpers used in the app:

- `#0B2740` for deep game surfaces and headers.
- `#12344D` for primary readable text on light surfaces.
- Keep danger red only for mines, wrong moves, and destructive actions.
